# 🔬 ISBCAPD Research Repository

This directory serves as the centralized knowledge base and research repository for the **Intelligent Swarm Based Bots for Continuous Area Patrolling and Detection (ISBCAPD)** project.

As the project evolves, all foundational engineering research, literature reviews, and theoretical analyses will be documented here. This ensures that all architectural and design decisions are backed by rigorous research and readily accessible to the team.
