PROJECT NAME
Intelligent Swarm based bots for Continuous area Patrolling and detection

WHAT THIS PROJECT IS
An autonomous multi-bot surveillance system. Each bot has an ESP32-CAM, mmWave Radar sensor, ToF sensor, and motor encoders. A laptop runs a Python AI script (YOLOv8s) to detect people from the camera feed. All sensor data is pushed to Firebase and displayed on a custom web dashboard.

HARDWARE STACK
ESP32-CAM: Streams MJPEG video over Wi-Fi to Python script
mmWave Radar Sensor: Detects movement, distance, presence — data shown on radar modal
ToF Sensor: Distance measurement
Motor Encoders: Tracks wheel speed/direction (KINETICS panel)
Bot chassis: Physical autonomous patrol vehicle
SOFTWARE / AI STACK
AI Model: Ultralytics YOLOv8s (Small) running via ONNX runtime
Python Server: Flask-based HTTP server running on http://127.0.0.1:5000
/feed → Annotated MJPEG live camera stream
/status → JSON telemetry: { inference_fps, threat_active, confidence, persons_in_frame }
Inference Mode: USE_FALLBACK_CAM = True (using laptop webcam right now, not ESP32-CAM)
Confidence Threshold: 70%
Temporal Smoothing: 5-frame window, requires 3/5 positive frames to confirm a detection
Firebase: Realtime Database at rob-track-default-rtdb.firebaseio.com — receives detection alerts
